# calculating
🎒 신비의 알: 역곱셈 퀘스트 (Mystery Egg Multiplication)
"구구단을 외우는 지루한 연산은 가라! 문제를 풀고 골드를 모아 전설의 동물을 부화시키는 환상의 수학 모험!" 
본 프로젝트는 학생들이 거꾸로 구구단(역곱셈)을 마스터할 수 있도록 게이밍 요소(Gamification)와 직관적인 모바일 UI를 결합하여 제작된 교육용 Streamlit 웹 애플리케이션입니다.

🎮 주요 기능 (Key Features)
1. 📱 스마트 3x3 키패드 및 실시간 피드백
아이들에게 익숙한 스마트폰 계산기 스타일의 가로형 3x3 숫자 패드를 제공합니다.
숫자를 누르는 즉시 문제창의 [ ? ] 칸에 실시간으로 반영되어 내가 어떤 숫자를 입력했는지 바로 확인할 수 있습니다.
잘못 눌렀을 때 당황하지 않고 수정할 수 있는 주황색 ⌫ 지우기 버튼이 포함되어 있습니다.

💰 2. 동기부여를 위한 골드 시스템
문제를 맞힐 때마다 8~13 골드가 무작위로 지급되어 성취감을 높입니다.
틀렸을 경우, 첫 번째 숫자를 가리켜주는 빨간색 힌트 기능이 작동하여 포기하지 않고 끝까지 문제를 풀 수 있도록 유도합니다.

🥚 3. 부르르 떨리는 3단계 알 부화 애니메이션
100 골드를 모으면 상점에서 신비의 알을 뽑을 수 있습니다.
알을 뽑으면 화면 중앙에 거대한 알이 나타나 2.5초 동안 부르르 떨리는 모션이 작동하며 긴장감을 선사합니다.
부화 시 등급에 따라 눈꽃 효과(희귀) 및 황금 폭죽 효과(전설)가 화려하게 펼쳐집니다.
